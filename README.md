# SQL Portfolio

## Welcome to my SQL portfolio!
This repository contains examples of SQL queries I have written while practicing database management and data analysis.
In this project, I worked with a Superstore database to:
- organize and sort data
- calculate statistics such as averages, totals, minimums, and maximums
- filter data by category
- identify high-priced items using SQL queries
  
The goal of this portfolio is to demonstrate my understanding of:
- SELECT statements
- ORDER BY
- aggregate functions (AVG, SUM, MIN, MAX, COUNT)
- WHERE clauses
- basic SQL data analysis techniques
